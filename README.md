# UploadFlow

Automatische Dateiübertragung für Windows per SFTP, FTP und FTPS.

Einmalige Aufträge oder Wiederholung im Intervall. Infoleiste mit Übertragungsstatus.

- [Programm für Windows x64](https://github.com/ptacha/UploadFlow/releases/download/v4.5.0/UploadFlow_4.5.0_Windows_x64.zip)
- [Quellcode](https://github.com/ptacha/UploadFlow/releases/download/v4.5.0/UploadFlow_4.5.0_source.zip)

ZIP entpacken. Start: `UploadFlow.exe`. Den Ordner `_internal` daneben behalten.
